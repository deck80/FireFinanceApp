# Architecture and Design Decisions

This document tracks the key decisions made during the development of the FireFinanceApp.

## Decision Log

### [ID-001] Tech Stack Selection (Decided)
- **Status**: Decided
- **Context**: We need to select a frontend framework and a cloud provider for hosting.
- **Options**:
    - Frontend: SvelteKit vs MERN (React)
    - Cloud: Oracle Cloud vs Azure
- **Decision**: SvelteKit + Oracle Cloud
- **Reasoning**: User preference. SvelteKit offers a modern, performant framework, and Oracle Cloud provides a generous free tier suitable for this application.
